# Домашнее задание

## Условие задачи
Дано число N (N<1000). Написать программу, которая проверяет
входит ли в него цифра 5.

---

## 1. Алгоритм и блок-схема

### Алгоритм
1. Начало функции. Получение целого числа n в качестве параметра.
2. Присвоение переменной temp абсолютного значения числа n (temp = |n|) для корректной работы с отрицательными числами.
3. Если temp равен 0, завершить выполнение и вернуть результат 0 (так как в нуле цифры 5 нет).
4. Начать цикл с предусловием while (temp > 0).
5. Если остаток от деления текущего числа на 10 равен 5 (temp % 10 == 5), завершить выполнение функции и вернуть результат 1 (цифра 5 найдена).
6. Разделить temp нацело на 10 (temp /= 10), отсекая последнюю проверенную цифру, и вернуться к шагу 4.
7. Если цикл завершился и цифра 5 не была найдена, вернуть результат 0.
8. Конец функции.

## 2. Реализация программы
```c
if (scanf("%d", &n) == 1)
{
    int has_five = mat(n);
    if (has_five)
    {
        printf("Цифра 5 входит в число\n");
    }
    else
    {
        printf("Не входит\n");
    }
}

int mat(int n)
{
    int temp = n < 0 ? -n : n;
    if (temp == 0)
    {
        return 0;
    }
    while (temp > 0)
    {
        if (temp % 10 == 5)
        {
            return 1;
        }
        temp /= 10;
    }
    return 0;
}
```
